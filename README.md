## 💻 Getting Started Locally

To clone, run, and explore the codebase locally:

```bash
# 1. Clone the repository
git clone https://github.com/RoshiniKrithi/PORTFOLIO-WEBSITE.git

# 2. Navigate to project root
cd PORTFOLIO-WEBSITE

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Building for Production

```bash
# Build optimized static production bundle
npm run build
```

The output will be placed in `./out`, ready to be hosted on Netlify, Vercel, Cloudflare Pages, or GitHub Pages.
